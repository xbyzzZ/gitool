# Gitool 提交按钮图标化与 Logo 设计

## 目标

解决提交信息视图在窄侧栏中因文字按钮折行而变形的问题，并为 VS Code Marketplace 提供清晰、可识别的 Gitool 扩展 Logo。

本次只改变按钮的视觉表达和扩展品牌资产，不调整提交信息区的布局、按钮分组、顺序、业务行为或可用状态规则。

## 按钮设计

现有 `commit-actions`、`ai-actions` 和 `primary-actions` 结构保持不变：AI 生成与密度选择仍位于左侧，“仅提交”与“提交并推送”仍位于右侧。

按钮内容改为 VS Code Codicon：

- AI 生成使用 `sparkle`；生成过程中在同一按钮内切换为旋转的 `loading`，点击仍执行取消生成；
- 密度选择使用 `chevron-down`；
- 仅提交使用 `git-commit`；
- 提交并推送使用 `cloud-upload`，继续采用主按钮配色。

四个按钮采用固定高度和紧凑宽度，不显示可折行文字。按钮通过 `title` 和 `aria-label` 保留完整中文含义；AI 生成与密度按钮的提示包含当前“精简、标准或详细”状态。禁用态、焦点态、键盘操作和提交安全条件保持不变。

## Logo 设计

Logo 采用已确认的“文件选择 + 向上推送”方向：

- 蓝青色圆角方形背景；
- 左侧白色文件轮廓与蓝色勾选标记，表达按文件选择；
- 右侧绿色向上箭头，表达提交并推送；
- 不包含文字、水印、阴影或小尺寸下无法辨认的装饰。

生成阶段先产出无文字的正方形高分辨率品牌图，检查构图后保存 512×512 PNG；再生成或缩放为 128×128 PNG 供 Marketplace 使用。最终资产写入项目 `media/`，不得仅保留在图像生成工具的默认目录。

`package.json` 使用 128×128 PNG 作为扩展商店图标。活动栏继续使用当前单色 `media/icon.svg`，因为活动栏图标需要适配 VS Code 明暗主题，不替换为彩色 Marketplace Logo。

## 实现边界

- 不修改提交、推送、AI 生成或密度选择的消息协议；
- 不改变按钮的左右布局、DOM 分组或显示顺序；
- 不改变无远程、无选中文件、冲突、未信任工作区和操作中状态下的禁用规则；
- 不修改当前变更与提交历史视图；
- 不提交 `.serena/project.yml` 或 `.superpowers/` 视觉预览文件。

## 验证

- HTML 渲染测试确认四个按钮包含正确 Codicon、中文无障碍名称和提示；
- Webview 状态测试确认 AI 图标在生成与空闲状态间切换，提示包含当前密度；
- CSS 测试确认按钮固定尺寸、文字不参与布局且窄侧栏不会折行；
- Logo 文件验证尺寸、PNG 格式和有效内容；
- `vsce ls --no-dependencies` 确认 Logo 被纳入 VSIX；
- 完整执行类型检查、ESLint、单元测试、构建和 Extension Host 验收。
