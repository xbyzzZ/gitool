## [S1] 问题

0.2 将提交信息、当前变更和提交历史拆成多个 VS Code 视图。用户必须在不同视图间移动和调节高度，文件选择与提交信息缺少同一任务上下文；提交历史又占用侧栏纵向空间。0.3 需要以 PyCharm Commit 工具窗口为基准，把日常提交路径收敛为一个连续面板，并暂时舍弃提交历史功能。

## [S2] 信息架构与布局

Gitool 活动栏仅贡献一个名为“提交”的 Webview View，移除“当前变更”和“提交历史”视图及历史专用命令入口。单一工作台从上到下为：工具栏、可滚动变更区、底部状态条、提交信息输入框和提交操作区。

```text
┌ 刷新 全选 清空 舍弃        拉取 推送 远程 ┐
├ 仓库 / 分支摘要（多仓库时可切换）          ┤
│ ▾ ☑ 变更                         13 个文件 │
│     ☑ [图标] file.ts    src/path         M │
│ ▸ ☐ 未进行版本管理的文件          2 个文件 │
│                                           │
├ AI 生成 / 档位 / 模型       已选择 13 / 15 ┤
│ 提交信息                                  │
│                                           │
├ [提交] [提交并推送]                  [设置] ┤
└───────────────────────────────────────────┘
```

变更区占据剩余高度并独立滚动，底部提交区固定可见。提交信息输入框默认约 104px，可随面板高度收缩但不得消失。0.3 不新增 amend 行为；截图中的“修正”位置用于现有 AI 控件与选择统计，避免出现无效控件。

## [S3] 变更树交互

变更按“变更”“未进行版本管理的文件”“冲突文件”分组，不再额外生成目录层级；文件名为主信息，目录作为同行弱化说明。分组支持展开/收起和整组选中，文件支持单独勾选与点击打开 Diff。已跟踪文件默认选中、未跟踪文件默认不选中的安全语义保持不变，冲突文件不可勾选。

文件图标继续读取当前 `workbench.iconTheme`，保持 14×14 画布；切换文件图标主题或颜色主题时动态重载。状态字母使用 Git 装饰色，不用额外徽章。窄于 340px 时优先隐藏目录说明，窄于 260px 时隐藏状态统计文字，但保留文件名、勾选框和主操作。

## [S4] 工具栏与提交区

顶部工具栏复用现有能力：刷新、选择全部变更、清空选择、舍弃所选未跟踪文件、拉取、推送全部和修改远程。危险的舍弃操作仍由既有服务弹出二次确认并移入系统废纸篓。按钮使用 Codicon、28px 点击区域、中文 aria-label 和 title；无可用上下文时禁用而非隐藏。

底部状态条保留 AI 生成、生成密度和当前模型选择，同时显示已选择数量与总变更数量。提交信息继续按仓库保存，操作区提供“提交”和“提交并推送”文字按钮；提交、推送失败与重试反馈显示在输入框上方或下方的固定反馈区，不得把按钮推出视口。

## [S5] 视觉与可访问性

界面使用 VS Code 的字体、前景色、侧栏背景、列表悬停/焦点、输入框和按钮主题变量，不引入独立品牌色、渐变、阴影或卡片圆角。文件行为 24px，分组行为 28px，工具栏为 32px；分隔线只编码工具栏、滚动区和提交区的结构边界。

所有按钮和复选框可通过键盘访问，分组按钮暴露 `aria-expanded`，复选框有明确名称，文件行支持 Enter 打开 Diff。加载、空数据、未信任、冲突和操作失败均提供可读状态。

## [S6] 范围外

- 0.3 不提供提交历史、分支拓扑、历史文件展开或历史 Diff 入口。
- 不新增 amend、代码块级提交、stash、rebase、cherry-pick 或强制推送。
- 不改变精确按路径提交、未跟踪文件安全选择、多仓库、AI 模型选择和推送失败重试语义。
- 不在本轮发布到 Marketplace；只生成 0.3.0 VSIX 供人工验收。

## [S7] 可调提交区与文字档位

文件列表与底部提交区之间增加水平分隔条。鼠标或触控笔上下拖动时实时调整提交区高度，键盘聚焦后支持方向键微调；高度必须按当前 Webview 可用空间限制，始终保留文件区与提交操作按钮。调整结果由 Webview 状态记忆，重新渲染和切换主题后保持。

AI 生成主按钮不再绘制星形图标，直接显示当前“精简”“标准”或“详细”；点击文字仍生成当前档位内容，右侧箭头继续调用 VS Code 原生档位选择器。生成过程中保留当前档位文字并显示紧凑加载指示，不改变 AI 模型选择流程。
